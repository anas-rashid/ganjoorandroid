# PoetRow

One poet as a list row, for readers who would rather scan names than faces.

- **Consumer provides:** the poet, whether they are pinned, and click / long-click handlers.
- Material ListItem: `avatar-row` (44px) portrait disc leading, name in `title-medium`, trailing pin mark plus the **DownloadStatus** for that poet.
- Same pin behaviour as PoetCard: long-press to pin; the pin mark shows only on pinned poets.
- The grid/list choice is a top-bar toggle and is remembered.
